# Admins

Admins see and edit everything, and there is no limit to their number.

- **Add an admin** with their email (first and last name are optional). They sign in like everyone else, with the email link.
- **Remove** an admin from the table, with confirmation.
- You cannot remove yourself, nor the last admin left, nor the initial one defined by the configuration (`ADMIN_EMAIL`): for that you need to change the configuration.

Removing an admin only takes away the role: they remain a regular participant.
